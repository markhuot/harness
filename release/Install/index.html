Harness

Release app-20261005.1743

Harness runs AI coding agents on your Mac and puts each one on a kanban board as a ticket. You describe the work and the agent does it on its own branch, and nothing merges until you've reviewed it.

The iPhone and iPad app shows the same board, so you can answer an agent's question or approve its work when you're away from your desk.

What it does

Every agent session is a ticket

Each job you hand an agent gets a card with a key like NYTIMES-4. The board shows what's in planning, what's running, what's waiting on you and what's ready for review, across every project on your Mac. Put projects in groups (Work and Personal, say) to give each group a board of its own.

Two reviews before anything lands

When an agent submits its work, a separate reviewer agent checks it, and then you give your own review. Approving can merge the branch, open a GitHub pull request, or follow instructions you write.

A worktree and a branch for each ticket

In a git project, each ticket works in its own worktree on its own branch, so several agents can work in one repo at the same time. The Changes tab shows everything a ticket changed against its base branch, uncommitted files included.

The same board on iPhone and iPad

Answer an agent's question, approve a command, read the transcript or approve finished work from your phone. The app connects straight to your Mac over Tailscale.

Watchers turn a feed into tickets

A watcher is any shell command that prints text (a Jira or Sentry poller, for example) plus a prompt that says what you want done with it. A triage agent reads each new item and either opens a ticket in the right project or declines it, and the Inbox shows every decision.

Big goals split into child tickets

A conductor ticket breaks a goal into child tickets with dependencies and starts each one when the work it waits on is done. The children merge into the conductor's branch, so the whole goal lands together.

You approve the risky commands

Agents edit files in their own workspace freely. A command the permission rules don't allow (installing a package, say) stops the ticket until you allow it once, allow it for the ticket, or deny it with a note.

Several tickets open side by side

Drag a card onto an open ticket to split the window, and keep the board, a ticket you're reviewing and one that's waiting on an answer in view at once. Each pane keeps its own tab and message box.

Watch the agent work

The Transcript tab streams every message and tool call as it happens, along with why each command was allowed. Send a follow-up from the box underneath whenever you want to steer.

A browser you can look over

Each ticket gets its own Chrome tabs to open your dev server, read docs or click through a flow, and you see them live. Annotate a screenshot to point at exactly what needs to change.

Everything from the keyboard

Press ⌘K to jump to any ticket, board or project group, or run a command. Search finds tickets by key or title across every project.

Getting started

  1. Get the Mac ready.

    Harness runs on an Apple silicon Mac with git. Agents run through the Claude Code CLI, signed in to your Claude team plan with claude auth login (an Anthropic API key in Settings works too). To use the iPhone app, install Tailscale on the Mac.

  2. Install the Mac app.

    Download Harness for Mac (below), unzip it, and drag Harness into your Applications folder. When you open it, it starts the background service that runs your agents. By default the service stops when you quit the app, so to keep agents running after you quit, open Settings → Service and click Install next to Start at login. macOS then starts the service whenever you log in.

  3. Add a project.

    Click + next to Projects in the sidebar and pick a folder you work in. A git repository works best, since each ticket then gets its own worktree and branch.

  4. Make a ticket.

    Press ⌘N, pick the project and describe what you want done. ⌘↩ starts the agent right away, and ⇧⌘↩ has it write a plan for you to approve first.

  5. Pair your iPhone or iPad.

    Get the iPhone app from TestFlight (below). Sign in to Tailscale on the phone with the same account as the Mac. Then open Harness → Settings → Network on the Mac, choose Tailscale, and scan the Pair a phone QR code with the phone's camera.

iPhone and iPad

The iPhone and iPad app is on TestFlight, Apple's app for installing apps before they're in the App Store.

Get it on TestFlight
  1. Install TestFlight from the App Store.
  2. Open this page on the iPhone or iPad and tap Get it on TestFlight.
  3. In TestFlight, tap Accept, then Install.
